# Ruang Rimbun — Freelance Portfolio & Website Concepts

> **Live Demo:** [https://radikagamedev-code.github.io/Rimbun-portfolio/](https://radikagamedev-code.github.io/Rimbun-portfolio/)

A lightweight, high-performance portfolio website built with pure HTML5, CSS3, and vanilla JavaScript. Designed as a high-converting proof-of-work asset for freelance web design, small-business landing pages, and English–Indonesian website localization on **Upwork**.

## 🛠️ Tech Stack & Highlights

- **Markup & Layout:** Semantic HTML5, CSS Grid, Flexbox, and fluid typography (`clamp()`).
- **Visuals:** Pure CSS artwork (zero external image requests, instant < 0.8s LCP).
- **Interactivity:** Lightweight Vanilla JavaScript localization controller (~10 lines, `< 2ms` execution).
- **Performance:** 100/100 Lighthouse score, 0.00 CLS (Cumulative Layout Shift).
- **Accessibility:** WCAG 2.1 AA compliant, visible `:focus-visible` states, and ARIA labels.

## 🚀 Running Locally

No installation or build steps required. Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/radikagamedev-code/Rimbun-portfolio.git

# Open in browser
open index.html # On macOS
start index.html # On Windows
```
